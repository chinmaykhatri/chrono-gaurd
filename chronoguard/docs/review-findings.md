## What remains open

- The local model missed 14/24 reference spans on paired WiCE inputs. Among 16 examples with incomplete support, three were confirmed. This small, balanced sample measures archival support, with false freshness defined as confirming a claim whose supplied document does not fully support it. It cannot establish a production stale-answer rate. [Observation-level results](../eval/reports/wice-local.json)
- Model-assisted regeneration returned the expected version for six supplied corrections. Errors unrelated to version strings and the accuracy of unrestricted web retrieval remain unmeasured. [Regeneration outputs](../eval/reports/grounded-repairs.json)
- Live Bifrost chat, extraction and judging were verified with the FreeModel model ID `claude-opus-5`. A replacement Tavily credential is still required to exercise the full search-and-repair path with external evidence or measure billed search credits. [Provider proof](../eval/reports/freemodel-live.json)
- Operators of existing remote instances must revoke historical provider keys, rotate service secrets and redeploy with the secured build. Publishing this change preserves repository history. The repository URL stays stable for reviewers.
- The project targets a Bifrost gateway extension with Tavily stale-answer detection. The project specifications refer to Bifrost PS04 and Tavily PS01. Confirm the organizer's labels in the actual submission portal. No submission or event registration was changed.

## Reproduce the security review

Run `python scripts/audit_credentials.py` from the application directory to scan the checkout. Run `python scripts/audit_credentials.py --history` for all locally reachable Git objects. A history finding makes that command exit with status 1. The scanner emits locations and categories and does not print matching strings. Its rules cover selected provider formats and the literal patterns involved in this review. Tests and static review cover the paths listed above. They do not constitute third-party certification of every source file.
